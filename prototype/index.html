00镜面交互原则（本原型的设计约束）

这是一面立在商场试衣间里的大尺寸竖屏落地镜，不是手机 App，也不是平板。顾客双手常常拿着衣服，因此交互以隔空手势为主、语音为辅、触控兜底——界面必须按「一米 UI」重做，而不是把 App 放大。

镜面即界面

中央默认保留实时镜面影像，试穿模型与推荐以暖白玻璃浮层挂在四周，不铺满整屏。

隔空手势为主

挥手换装、左右挥切换单品、握拳收藏、上下挥切尺码；全程无需触碰屏幕。

一米可读

正文基准 ≥24px（镜面画布），标题 42–58px，数字 92px+；触控目标高度 ≥66px。

贴边竖向导航

用左缘细长竖向模块栏替代手机底部 tab 栏；无状态栏、无刘海、无信号电量。

01产品定位与场景

场景锁定商场零售品牌试衣间：空间狭小、顾客手上拿衣服、传统试衣无法预览搭配、缺码空手而归。魔镜把「照镜子」这件零成本动作，直接升级为试穿—搭配—下单的完整闭环。

角色定位

从「穿衣镜」升维为门店的虚拟试衣导购 + 线上转化入口。

核心价值

试得更多（不脱衣换装）、搭得更好（整身推荐）、买得到（库存联动）。

关键动作

顾客拿一件实体衣服站到镜前 → 自动识别同款 / 搭配推荐。

交付形态

竖屏落地镜，一体化成型，无需门店改造布线。

04隔空手势交互规范（无接触）

手势是第一交互方式：顾客双手常被衣服占用。四式手势覆盖试衣主循环，语音与触控作为辅助与兜底。

识别距离

0.5–1.5m 最佳识别区，超出范围时镜面提示「请站近一点」。

容错与防误触

手势需持续 ≥0.3s 且幅度达标才触发；相邻两次手势设 0.5s 冷却，避免连触。

语音辅助

底部常驻语音入口；「换一件 / 换尺码 / 收藏 / 下单」与手势等价。

可发现性

首次进入试衣即展示手势提示，并在每次成功后给出明确反馈。

RFID 识别链路

顾客举起带标签的实体商品 → 读写模块 30cm 内读取 EPC → 匹配 SKU → 镜面展示同款详情 + 尺码 + 搭配推荐 → 一键试穿或加购。

门店库存链路

镜面实时读取门店 ERP 库存，只呈现真实可售尺码；缺码时自动给出「调货」或「线上发货」选项，避免试得好看却买不到。

价值闭环：线下试衣体验 → 线上订单 / 门店现货 → 会员数据沉淀。镜子既是体验入口，也是转化入口。

07落地与风险提示

灯光色偏

试衣间灯光会改变衣物显色。以屏幕色温补偿 + 户外基准色作为参照，降低「买回家颜色不对」的退货率。

建模精度

5 秒建模对深色 / 宽松服装的体型还原有限，尺码建议需叠加人工试穿确认，不做绝对化承诺。

隐私合规

人体建模属敏感个人信息，须明示用途、本地处理、不上传原始影像，并提供一键清除。

RFID 可靠性

金属纤维面料、叠放遮挡会降低读取率；以「手动搜索同款」作为兜底路径，避免识别失败即中断。

库存一致性

门店与线上库存需高频同步；对低库存商品给出「仅剩 N 件」提示，减少超卖与顾客落空。

评测呈现

本原型以浏览器打开即可评审；摄像头仅在本机 localhost / https 下生效，本地文件直开时自动降级为模拟镜面。Chrome / Edge 为基准浏览器。
